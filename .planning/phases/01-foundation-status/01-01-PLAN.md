<task type="auto">
  <name>Task 1: Create gsd executable with constants, colors, utilities, and error handling</name>
  <files>gsd</files>
  <action>
Create the file `gsd` (no extension) with `chmod +x`. Structure it following Google Shell Style Guide (constants top, main bottom, `main "$@"` last line).

**Header:**
- `#!/usr/bin/env bash`
- `set -euo pipefail`

**Constants section (all `readonly`):**
- `VERSION="0.1.0"`
- `QUEUE_FILE="${GSD_QUEUE_FILE:-$HOME/dev/punchlab/QUEUE.md}"` — env var override per §9
- `LOG_DIR="${GSD_LOG_DIR:-/tmp}"` — env var override per §9
- `STUCK_THRESHOLD_MIN="${GSD_STUCK_THRESHOLD:-30}"` — env var override per §9 (NOTE: not readonly since --threshold flag can override at runtime)
- `PROG_NAME="gsd"`

**Color system — `setup_colors()` function:**
- Check `[[ -t 1 ]]` AND `[[ -z "${NO_COLOR:-}" ]]` AND `[[ "${TERM:-}" != "dumb" ]]`
- If all true: set RED, GREEN, YELLOW, BLUE, CYAN, BOLD, DIM, BOLD_RED, RESET using `$'\033[...]'` syntax
- BOLD_RED is `$'\033[1;31m'` for critical stuck/kill warnings
- If any false: set all to empty string
- Color vars should NOT be readonly (they're set by function call, not at top level)

**Utility functions:**
- `err()` — prints `"${RED}Error: $*${RESET}"` to stderr (§3.4)
- `warn()` — prints `"${YELLOW}Warning: $*${RESET}"` to stderr (§3.4)
- `debug()` — prints `"${DIM}[debug] $*${RESET}"` to stderr ONLY if `VERBOSE=true` (§3.4.4)
- `die()` — calls `err "$@"` then `exit 1` (§4.2)
- `die_usage()` — calls `err "$@"`, prints "Run 'gsd --help' for usage." to stderr, then `exit 2` (§4.3, §1.6, §1.7)
- `cleanup()` — removes `"${TMPFILE:-}"` if set; registered via `trap cleanup EXIT` (§10.7)
- `check_deps()` — check `command -v jq` and `command -v opencode`, die with install instructions if missing (§7.5). Use `die` not `die_usage` since this is runtime error.
- `format_duration()` — takes seconds as `$1`, printf "Xh Ym" / "Xm Ys" / "Xs" per §3.3. Use arithmetic: `hours=$((seconds / 3600))`, `minutes=$(( (seconds % 3600) / 60 ))`. Guard against non-numeric input with `[[ "$1" =~ ^[0-9]+$ ]] || { printf 'unknown'; return; }`.

**Important bash pitfall mitigations:**
- ALL variable expansions quoted (§10.2, Pitfall #1)
- `local var; var=$(cmd)` pattern — never `local var=$(cmd)` (Pitfall #4)
- `[[ ]]` for all conditionals (§10.3)
- `printf` for all output, never `echo -e` (§10.6, Pitfall #6)

<task type="auto">
  <name>Task 2: Add main dispatch, global flag parsing, help/version, and subcommand stubs</name>
  <files>gsd</files>
  <action>
Add to the existing `gsd` file (in the appropriate sections per Google Style Guide ordering):

**Help text — `usage()` function:**
- Print usage summary with: tool name, version, synopsis, available commands (status, queue/q, stuck, log, tail), global options (-v/--verbose, --json, -h/--help, --version), environment variables (GSD_QUEUE_FILE, GSD_LOG_DIR, GSD_STUCK_THRESHOLD, NO_COLOR), and 2-3 examples
- Use printf for all output. Use color variables for headers/emphasis.
- Exit after printing (don't add exit in the function — let caller handle)

**Per-subcommand help stubs** — create `status_usage()`, `queue_usage()`, `stuck_usage()`, `log_usage()`, `tail_usage()`:
- Each prints subcommand-specific help: synopsis, description, flags, examples
- These should be useful real help text, not "TODO" placeholders

**Subcommand stub functions** — `cmd_status()`, `cmd_queue()`, `cmd_stuck()`, `cmd_log()`, `cmd_tail()`:
- Each parses its own flags via `while [[ $# -gt 0 ]]; do case "$1" in` loop (§1.8, not getopts)
- Support `--` to terminate flag parsing (§1.9)
- Support `-h`/`--help` to show subcommand help (§1.13)
- `cmd_status()`: parse `--verbose`/`-v` locally (in addition to global). Body prints placeholder "Status dashboard coming in Plan 02"
- `cmd_queue()`: no extra flags beyond -h. Body prints placeholder.
- `cmd_stuck()`: parse `--threshold N`/`-t N` (validate numeric), `--kill`/`-k`, `--force`/`-f`. Body prints placeholder.
- `cmd_log()`: require positional `<session>` arg (die_usage if missing per §2.4.4). Body prints placeholder.
- `cmd_tail()`: require positional `<session>` arg (die_usage if missing per §2.5.1). Body prints placeholder.

**Main dispatch — `main()` function:**
- Call `setup_colors` first
- Parse global flags with `while [[ $# -gt 0 ]]; do case "$1" in` (§1.5):
  - `--verbose|-v` → set `VERBOSE=true` (exported so subcommands see it)
  - `--json` → set `JSON_OUTPUT=true` (exported); also re-call `setup_colors` to disable colors (§3.1.5)
  - `--help|-h` → call `usage; return 0`
  - `--version` → `printf '%s\n' "gsd ${VERSION}"; return 0` (§1.11)
  - `-*` → `die_usage "Unknown option: $1"` (§1.6)
  - `*` → `break` (first non-flag = subcommand)
- After flag loop: `local cmd="${1:-status}"` (§1.4 default to status), `shift || true`
- Call `check_deps` (§7.5 — fail fast)
- Case dispatch on `"${cmd}"`:
  - `status` → `cmd_status "$@"`
  - `queue|q` → `cmd_queue "$@"` (§2.2.8 alias)
  - `stuck` → `cmd_stuck "$@"`
  - `log` → `cmd_log "$@"`
  - `tail` → `cmd_tail "$@"`
  - `help` → `usage`
  - `*` → `die_usage "Unknown command: ${cmd}. Run 'gsd --help' for usage."` (§1.7)

**Last line of file:** `main "$@"` (§10.1)

**VERBOSE and JSON_OUTPUT** should be initialized as `false` at the top of main (not as global constants) — they're runtime state, not configuration.
